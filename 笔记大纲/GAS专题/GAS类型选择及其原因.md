# GAS 类型选择及其原因

> 基于 UE5.3 学习视频第3章第2节字幕整理

---

## 一、GAS 的核心组成部分

GAS 由以下几个关键部分构成：

### 1.1 能力系统组件（Ability System Component, ASC）
- 一种可以添加到 Actor 上的**组件类型**
- 负责处理 GAS 中的核心事务：
  - **赋予能力**（Grant Abilities）
  - **激活能力**（Activate Abilities）
  - 处理能力激活/效果应用的**通知**
  - 以及其他许多重要功能
- 角色必须拥有 ASC 才能参与 GAS 系统

### 1.2 属性集（Attribute Set）
- 几乎所有游戏都涉及与对象/角色关联的多个属性
- 属性范围从生命值、魔法值到任何你能想到的属性
- 属性集将属性与 GAS 的其他部分关联起来

### 1.3 游戏能力（Gameplay Ability）
- 用于**封装**角色或物体可以执行的某种功能
- 例如：攻击、施法
- 将所有代码和功能保持在特定的游戏能力类中
- 能力运行**异步任务**（Ability Tasks）：
  - 可能立即执行并完成
  - 也可能跨越一段时间，做不同的事情
  - 能力任务是执行游戏能力工作的"工人"

### 1.4 游戏效果（Gameplay Effect）
- 用于**改变属性值**
- 可以：
  - 直接改变属性
  - 随时间推移改变属性
  - 定期增加或减少属性
  - 将属性变化与各种计算关联（考虑其他参数和属性）

### 1.5 游戏提示（Gameplay Cue）
- 负责处理**外观效果**：
  - 粒子系统（Particle Systems）
  - 声音（Sounds）
- 也能处理这些效果的**网络复制**

### 1.6 游戏标签（Gameplay Tag）
- 并非 GAS 专属，可独立使用
- 用于**识别几乎所有东西**
- **层级结构**使其比枚举、布尔值或字符串更灵活
- 在 GAS 中无处不在

## 二、ASC 和属性集放在哪里的选择

> 核心问题：**ASC 和属性集是放在 Pawn（角色）上，还是放在 PlayerState（玩家状态）上？**

### 2.1 方案A：放在 Pawn 上

**适用场景**：简单的敌人/NPC

**优点**：
- 简单直接
- 适合不需要玩家状态的简单敌人
- 敌人只需有属性和能力，按 AI 逻辑操作即可

**缺点**：
- 角色死亡被销毁时，ASC 和属性集也一起消失
- 如果不额外保存数据，复活后所有属性和能力回到默认值
- 属性与角色绑定，换角色时会丢失

---

### 2.2 方案B：放在 PlayerState 上

**适用场景**：玩家控制的角色

**优点**：
- PlayerState 与 Pawn 关联但**独立存在**
- Pawn 死亡被销毁时，ASC 和属性集**不会丢失**
- 生成新 Pawn 并关联 PlayerState 后，属性和能力保持不变
- 支持**角色交换**：属性与玩家绑定而非特定角色
- 适合需要复活机制或角色切换的游戏

**缺点**：
- 需要额外创建 PlayerState 类
- 架构稍复杂

---

### 2.3 本项目采用的方案

| 角色类型 | ASC 和属性集位置 | 原因 |
|----------|-------------------|------|
| **玩家控制的角色** | PlayerState | 支持复活/换角色时保留属性和能力 |
| **敌人角色** | 直接放在角色类（Pawn）上 | 敌人简单，不需要 PlayerState，按 AI 逻辑操作 |

> 这样做的好处：**两种方式都能接触到**，便于对比学习。

---

## 三、需要创建的基础类

为了在项目中实现 GAS，需要以下基本类：

1. **PlayerState 类** — 用于承载玩家的 ASC 和属性集
2. **Ability System Component 类** — 添加到 PlayerState 上
3. **Attribute Set 类** — 定义角色的属性

这些类将与已有的 **PlayerController** 和 **Character** 类关联。

## 四、决策总结

```
┌─────────────────────────────────────────────┐
│             GAS 架构选择                      │
├─────────────────┬───────────────────────────┤
│   玩家角色       │      敌人/NPC             │
├─────────────────┼───────────────────────────┤
│ ASC → PlayerState│  ASC → Pawn              │
│ AttrSet → PlayerState│ AttrSet → Pawn       │
├─────────────────┼───────────────────────────┤
│ 原因：持久化     │  原因：简单直接            │
│ 支持复活/换角色  │  不需要 PlayerState       │
└─────────────────┴───────────────────────────┘
```
